# Curated Resources Library

## Essential Books

| Title | Why It Matters |
|-------|---------------|
| **Real-Time Rendering 4th ed.** | The TA bible. Every TA should own it. |
| **Physically Based Rendering (PBRT)** | Theoretical depth, free online version |
| **GPU Gems 1-3** (NVIDIA, free) | Classic techniques; the reasoning approach never goes out of date |

## Annual Must-Reads

- **SIGGRAPH Advances in Real-Time Rendering**: Updated annually, covers the latest industry techniques
- **GDC Vault**: Released annually after GDC; search "Technical Artist" or "Rendering"
- **I3D (Interactive 3D Graphics)**: Real-time rendering research papers
