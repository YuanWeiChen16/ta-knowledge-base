# 視覺直覺訓練（程式師的刻意練習）

**程式師最難建立、但最值得投資的能力。**

---

## 為什麼視覺直覺對 TA 很重要

TA 的工作不只是「讓 shader 跑起來」，而是能判斷：
- 這個材質的 Roughness 值對嗎？
- 這個光照讓場景感覺「廉價」嗎？
- 這個 VFX 和美術的意圖一致嗎？

**沒有視覺直覺的 TA = 只會寫程式碼的人。**  
工程師能完成技術任務，TA 能讓技術服務視覺目標。

---

## 視覺直覺訓練方法

### 方法 1：截圖分析（每日 5 分鐘）

```
練習：
1. 每天截一張你喜歡的遊戲場景截圖
2. 問自己：
   - 光源在哪裡？幾個？顏色是什麼？
   - 地面材質的 Roughness 大概是多少？（0-1 估）
   - 天空是 HDR 環境光還是 Directional Light 主導？
   - 這個畫面如果你要在 UE5 重現，第一步做什麼？

不需要寫下來。每天重複，3 個月後你的「眼睛」會改變。
```

### 方法 2：材質球練習

```
目標：建立 Roughness/Metallic 的感知對應

練習：
1. 在 UE5 建立一個球體矩陣（5×5）
2. X 軸：Roughness 0.0 到 1.0
3. Y 軸：Metallic 0.0 到 1.0
4. 在不同光照環境下截圖
5. 閉眼後，給自己一個真實物件（「濕石頭」「拋光銅」「舊木頭」）
   → 估測它的 Roughness 和 Metallic 數值
   → 打開 UE5 驗證

反覆練習直到估測誤差 < 0.15
```

### 方法 3：Shadertoy 美觀練習（非技術）

```
不同於技術練習，這個練習純粹追求「好看」：

1. 在 Shadertoy 用最簡單的幾何（SDF 圓）
2. 只調顏色、漸層、對比度
3. 目標：讓它看起來「專業」

評判標準不是技術複雜度，是「你會把這個當壁紙嗎？」

這個練習訓練你的色彩直覺和構圖感。
```

### 方法 4：拆解你欣賞的作品

```
選一個你覺得很棒的視覺效果（遊戲截圖、ArtStation 作品），
用 TA 的角度分析：

問題清單：
□ 這個效果是在哪個 render pass 發生的？
□ 需要哪些貼圖輸入？（Albedo? Normal? Emissive?）
□ 有沒有使用到 Post Process？
□ 如果用 UE5 Material Editor 做，需要多少個節點？
□ 這個效果在行動裝置上成本可接受嗎？

每週分析 2 個作品，3 個月後你會發現自己能快速「看透」效果的製作原理。
```

## 色彩理論快速入門（程式師版）

程式師習慣用 RGB 數字思考顏色。這裡是視覺工作者的思維框架：

```
HSL vs RGB 思維方式：
  RGB (程式師)：(255, 128, 0)  ← 精確但不直覺
  HSL (視覺)：色相 30°, 飽和 100%, 明度 50%  ← 直覺

  實用對應：
  - 色相（Hue）= 顏色種類（紅/綠/藍/...）
  - 飽和度（Saturation）= 顏色的「純度」（0 = 灰色，100 = 鮮豔）
  - 明度（Lightness）= 亮暗

互補色法則（快速讓畫面有對比）：
  - 色相環上相對的顏色互補
  - 暖光（日落橘）→ 冷影（藍紫陰影）= 電影感
  - 冷光（月光藍）→ 暖影（棕橘）= 戲劇感

PBR 顏色限制（重要！）：
  Base Color：依材質參考或量測資料設定；確認數值使用 Linear 還是 sRGB
  金屬 Base Color：反映金屬的有色導體反射；依所選 shader 與色彩空間核對參考值
```

| 資源 | 用途 |
|------|------|
| **ArtStation** | 每天瀏覽 TA / Environment / VFX 類別的作品 |
| **80.lv** | 有製作流程說明的技術美術文章，邊看美術邊理解技術 |

| **Substance 3D Materials** | Adobe 官方材質庫，每個材質都有精確的參數，拿來校準感知 |

## 程式師的常見視覺盲點

```
1. 過度追求「正確」忽略「好看」
   症狀：物理正確的材質，但在場景裡看起來格格不入
   解法：先問「這看起來像預期效果嗎？」再問「這在數學上正確嗎？」

2. 不重視構圖和光照方向
   症狀：shader 技術正確，但截圖沒有視覺重心
   解法：學習攝影的「三分法」和「光的故事性」

3. 顏色用 RGB 數字決定
   症狀：顏色搭配看起來隨機
   解法：用色相環選顏色，不要直接輸入數字

4. 認為「更多細節 = 更好看」
   症狀：材質加了很多貼圖，但視覺上反而雜亂
   解法：學習「視覺層次」—— 近景精細，遠景簡化

5. 忽略光照對材質的影響
   症狀：在一個光照環境做好的材質，換環境就崩潰
   解法：在多種光照（室外強光、室內暖光、夜晚冷光）下測試每個材質
```
